# 🍕 Hotel Delivery System - Customer & Manager App

A complete Flutter-based food delivery application that serves both **customers** and **hotel managers** with a unified login system. Customers can browse restaurants, order food, and leave reviews, while hotel managers can manage their menu, track orders, and analyze business performance.

## 📱 Features

### 👤 Customer Features
- 🔐 **Authentication** - Register/Login with role-based access
- 🏨 **Browse Hotels** - View all available hotels and restaurants
- 🍽️ **Food Menu** - Browse products with images, prices, and descriptions
- 🛒 **Shopping Cart** - Add/remove items, adjust quantities
- 💳 **Multiple Payment Methods** - Cash on Delivery & Telebirr integration
- 📦 **Order Tracking** - Real-time order status tracking
- ⭐ **Reviews & Ratings** - Rate and review products
- 👤 **Profile Management** - Update personal information and profile picture
- 🔍 **Search & Filter** - Search products by name, filter by category

### 🏨 Hotel Manager Features
- 📊 **Dashboard** - View key metrics and statistics
- 📦 **Order Management** - View customer orders, update order status
- 🍕 **Product Management** - Add, edit, delete products with images
- ⭐ **Review Management** - View and analyze customer reviews
- 📈 **Analytics** - Track revenue, orders, and top products
- 👤 **Profile Management** - Update hotel information and manager profile
- 🏨 **Multi-Hotel Support** - Manage multiple hotels from one account

## 🛠️ Tech Stack

- **Framework**: Flutter 3.x
- **State Management**: Provider
- **API Integration**: HTTP & Dio
- **Image Loading**: Cached Network Image
- **Image Upload**: Image Picker
- **Authentication**: JWT with Shared Preferences
- **Charts**: FL Chart / Syncfusion Flutter Charts
- **Payments**: Telebirr Integration
- **Storage**: Shared Preferences
